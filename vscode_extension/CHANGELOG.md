# Changelog

## [1.0.0] — 2026-04-03

### Added
- Initial release of AI Code Masker VS Code extension
- Mask Selection (Ctrl+Shift+M) and Mask File (Ctrl+Shift+Alt+M) commands
- Unmask Selection (Ctrl+Shift+U) and Unmask File (Ctrl+Shift+Alt+U) commands
- Mask & Copy to Clipboard command
- Interactive Mapping Panel (webview) with copy, download, clear actions
- Status bar indicator showing masking state per file
- Editor right-click context menu integration
- Sensitive pattern detection (emails, AWS keys, tokens, IPs)
- Custom masking rules via settings
- Per-file mapping persistence across VS Code restarts
- Support for Python, Java, JavaScript, TypeScript, React, Vue, Svelte
