FREQUENTLY ASKED QUESTIONS

Everything you need to know about AI Code Masker security model.

How does the Code Masker work offline?

All character scanning, regular expression matching, mapping tables, and substitutions occur entirely inside your browser's heap memory using client-side JavaScript. Since no fetch requests or network calls are triggered during execution, your code remains fully isolated.

What happens to the Restoration Map?

The restoration map is compiled locally and printed to the map panel. You can copy it as a local JSON string. To restore your original code later, simply toggle the "Restore" mode, paste the masked code into the input, verify your map JSON is in the restoration panel, and click execute.

Can I customize the masking options?

Yes. Under the settings panel, you can choose to mask specific identifiers (functions/variables), secrets & tokens (AWS keys, OpenAI strings), or general literal strings.
