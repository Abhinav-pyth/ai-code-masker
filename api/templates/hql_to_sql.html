SQL Output
Entity & Column Names
Java entity names (e.g. Employee) map to snake_case tables (employee). Java camelCase properties (e.g. e.firstName) map to snake_case columns (e.first_name).
Parameters & Joins
Named params like :minSalary become positional ? (JDBC-style). Association paths like JOIN e.department d expand to JOIN department d ON d.id = e.department_id.
Implicit Paths
Three-level paths like e.department.name are expanded to the related table reference (department.name) with a logged warning to add the JOIN manually.
